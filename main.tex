\section{Introduction} \label{sec:intro}
This evidence looks at finding an automaton to accept a provided language. 
The resulting automaton can than be either modeled using Prolog or REGEX.
The language chosen for this evidence posesses the alphabet $\Sigma = \{0, 1, 2\}$, needs to end in either "111" or "122" to 
transition into an accepting state and prohibits the occurence of "211".
\section{Automaton} 
As \cite{hopcroft2001introduction} mention, (deterministic) finite automaton are useful models for different tasks, including lexical analysis.
When interpreting finite automatons as transition graphs, this can be easily visulaized.
A string can be broken down into each letter, which can be used to follow a graph into a specific node/ state.
In \cite{hopcroft2001introduction} a deterministic finite automaton is defined as a
quintuple $A= (Q, \Sigma, \delta, q0, F)$ where
\begin{itemize}
    \item Q defines a finite set of states,
    \item $\Sigma$ a finite alphabet,
    \item $\delta$ a transition function,
    \item q0 the inital state and
    \item F the accepting states.
\end{itemize}
An input gets accepted if, after passing the string, it ends up in an accepting
state, otherwise it is rejected. The alphabet $\Sigma$ is the same as mentioned in \cref{sec:intro} and
the other elements are yet to be determined.

While \cite{hopcroft2001introduction} also mention the existence of non-deterministic finite automaton,
due to the small size and lower complexity of the language, a deterministic model approach was chosen.
As \cite{hopcroft2001introduction} explain, a non-deterministic model has to be converted to a deterministic model,
in order to be implementable. As using a deterministic model was possible, this option was more reasonable.

Each string should start out at the same entry state E. From there one can derive the different conitions path, the automaton needs to recognize.
In \cref{fig:base_model} the different paths are depicted. The path s1e-s1f shows the accepted ending sequence "111", 
s1e-s2f models the accepting end string "122" and s3e-s3f show the rejected sequence "211". These are also all the required 
states, as any other sequence has no influence on acceptance or reejction and can lead back to E. With this F is defined as $F=\{s1f, s2f\}$.
In \cref{fig:full_model}, the full model is shown with all connections. Important to note is, that each node needs
to model each possible alphabet transition. Interesting observations include, that each 0
loops back to node E as 0 is no part of any important sequence, that once s3f is reached, all further transitions loop back to itself. 
Once this node has been reached, the string cannot be accepted. Further interesting to observer are the
transitions between different branches, as each subsequence in a branch can potentially be the starting point of a different sequence.
